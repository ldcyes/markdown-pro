# Markdown Pro v0.2.16

## Fixes

- Fix opening another Markdown file while the desktop editor is already running: the main window can now receive file-open events and activate the requested document. The permission fix covers the Windows/Linux single-instance path and the macOS open-file event path. Existing tabs are retained.
- Restrict desktop-only instance and window APIs to desktop targets, fixing the Android/iOS Rust compilation errors found during cross-platform verification.

## Downloads

| Platform | Architecture | Package |
| --- | --- | --- |
| Windows | x64 | `.exe` (NSIS) or `.msi` |
| macOS | Apple Silicon | `.dmg` |
| Linux | x64 | `.deb` or `.AppImage` |

## Verification and known limits

- 69 unit tests pass. Real browser UI tests cover switching A → B → A using mocked native events; Web file-chooser uploads also pass.
- Windows, macOS, Linux, Android and Web builds passed for the fix. Native desktop file-manager double-click and mobile device tests remain unverified.
- iOS Rust compilation passes, but the simulator package is blocked by Xcode Swift compatibility-library linking errors; no iOS package is included.
- Android external file-manager opening is not implemented in the current application/SDK path. Android APKs are build artifacts, not part of this desktop release.
- macOS/iOS cold-start file events are not buffered by the existing backend; that separate case remains outside this fix.
