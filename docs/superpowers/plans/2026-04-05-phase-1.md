# MarkdownPro Phase 1 Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the Phase 1 Markdown editing workflow on top of the existing Phase 0 ProseMirror scaffold.

**Architecture:** Keep Markdown/file/theme logic in focused TypeScript helpers and let the React editor shell wire them into ProseMirror commands, layout, and persistence. Favor pure modules for unit coverage and browser-only wrappers for integration points.

**Tech Stack:** React 19, TypeScript, ProseMirror, markdown-it, lucide-react, TailwindCSS, Node test runner
